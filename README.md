# My Cinema Vault

saya ingin membuat website pribadi saya, yaitu draft film/series netflix yang saya tonton dan yang saya suka, contohnya adalah can this love be translated yang saya beri nilai 9.95/10. saya juga ingin mencantumkan video trailernya seperti yang sudah saya lampirkan diatas. buatkan sebagus dan semenarik mungkin mulai dari fitur dan UI/UX nya. oh iyaa saya juga ingin web ini bisa tambah nama film/series, penilaian, dan video trailernya secara manual di website (bukan di codingan). Pokoknya buatkan sebagus mungkin dan saya serahkan kepada anda apa saja fitur yang bagus dan cocok. oh iya saya juga ingin di setiap series/film nya ada photo profile nya seperti pada gambar yang saya cantumkan
